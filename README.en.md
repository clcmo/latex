# LaTeX Site — Document publishing

A site for compiling and publishing LaTeX documents as PDF and HTML on GitHub Pages, organized by theme.

## How it works

LaTeX `.tex` documents live in `src/`, organized by category. GitHub Actions
compiles each document, generates its HTML version (with rendered math) and publishes an index by theme, a viewer with the PDF and HTML side by side, and a project presentation.

## Structure

```text
assets/
  css/                 Site styles
  js/                  Site behavior
  python/              Generators for the index, viewers, theme colors and READMEs
content/
  en.md                Source for this README
  pt-br.md             Source for the Portuguese README
  temas.json           Themes (name, description, color) and presentation slides
src/
  articles/            Articles and papers
  cv/                  Resumes
  math/                Mathematics notes
  slides/              Beamer presentations
templates/             HTML site templates
scripts/build.sh       Local and CI build
```

## Add a document

1. Create a `.tex` file in `src/articles/`, `src/cv/`, `src/math/`, or
   `src/slides/`.
2. If possible, add `\title{Document title}` so the title appears in the index.
3. Run `bash scripts/build.sh` and inspect the generated files in `site/`.

The build requires Python 3 and `pdflatex` (TeX Live). `pandoc` is optional: without it, the site only has the PDFs. Documents that use `fontspec` are compiled with `lualatex`; the others with `pdflatex`.

## Themes

The folder in `src/` sets the document **type** (article, resume, slides, notes). The **theme** sets which section of the site it appears in and which accent color it uses.

1. To choose the theme, write at the top of the `.tex`: `% tema: fisica`.
2. Without that line, the default theme comes from the type (see `padrao_por_tipo` in `content/temas.json`).
3. To create or edit a theme, change `content/temas.json` (name, description and `#rrggbb` color).
4. To skip the HTML version of a document, write `% html: off` at the top of the `.tex`.

The HTML version is generated by `pandoc` and is an approximate conversion: documents with many packages (TikZ, colored boxes) may lose formatting. The PDF remains the reference version.

## Publish on GitHub Pages

Set **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Pushes and pull requests to `main` compile the documents; pushes to `main`
publish the site.

## Update the READMEs

Edit `content/pt-br.md` and `content/en.md`. The build generates `README.md`
and `README.en.md` from these source files.
